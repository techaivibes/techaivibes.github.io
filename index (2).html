How to Write Better AI Prompts: A Simple Formula

Learn a repeatable prompt formula with examples for studying, writing, research and social content.

A useful prompt states the goal, context, audience, constraints, output format and what a good result should include.

Use the six-part prompt formula

Write your prompt using these parts: Goal (what you need), Context (relevant background), Audience (who it is for), Constraints (length, tone, exclusions), Format (table, bullets, script or checklist), and Quality checks (what the answer must include or verify). You do not need every part for every request, but the structure helps when a task is complex.

Example: from vague to useful

Vague: “Write a Reel script about AI.” Better: “Create a 15-second Hinglish Instagram Reel for beginners about one practical AI feature. Audience: Indian students and creators. Format: a one-line hook, three short voiceover lines and a final CTA. Keep it faceless and possible to produce on a phone. Avoid unsupported claims and explain the feature simply.” The second prompt provides a clear target and boundaries.

Ask for evidence when facts matter

For factual or current topics, ask the assistant to distinguish verified facts from assumptions, cite primary sources, and say when information is uncertain. Then open the sources yourself. A confident tone is not proof that an answer is correct.

Improve the first draft

If the response is close but not right, give targeted feedback. For example: “Keep the structure, make the hook more specific, remove repeated points, and keep each sentence under 12 words.” One focused revision is often more effective than starting over.

Save prompts that work

Keep a small library of prompts for recurring jobs such as research outlines, video scripts, email drafts and content calendars. Add placeholders like [topic], [audience] and [tone] so you can reuse the pattern without repeating irrelevant details.

Key takeaway

Prompting is clear communication, not a secret phrase. State what success looks like, add useful context, specify the output and review the result before publishing.
